# k6

Ferramenta de teste de carga. Roda como o service `k6` em `docker-compose.tools.yml`.

## Para que serve

Executa scripts de load test contra os serviços do monorepo (por padrão, o LocalStack; scripts específicos, como o do core-server, miram outro alvo) para validar throughput/latência sob carga antes de deploy.

## Como funciona

- Imagem `grafana/k6:latest`.
- Scripts em **TypeScript nativo** — sem passo de build, suportado desde o k6 v0.57.
- **Não é um serviço de longa duração**: tem `profiles: ['load-test']`, então não sobe junto com `docker compose up` normal — só roda sob demanda, uma execução por vez.
- Scripts ficam em `infrastructure/local/k6/`, montados como volume read-only em `/scripts`.
- Cada script declara seu próprio alvo via `__ENV.K6_TARGET_URL ?? <default>` — o alvo é responsabilidade de cada script, não do compose.

## Como usar

```bash
pnpm infra:load-test               # roda k6/smoke.ts contra o LocalStack (default)
pnpm infra:load-test:core-server   # roda k6/core-server-health.ts
```

Ou diretamente:

```bash
docker compose -f infrastructure/local/docker-compose.yml -f infrastructure/local/docker-compose.tools.yml \
  run --rm k6 run /scripts/<arquivo>.ts
```

Para mirar um alvo diferente do default, defina `K6_TARGET_URL` antes de rodar o script (verifique o script específico para saber se ele lê essa env var).
